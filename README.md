# Neon Gateway

A free 3D browser driving game. Drift through a neon night city and escape the police, tanks, and helicopters.

## Play locally
Open `index.html` in a modern browser. The game loads Three.js and post-processing scripts from public CDNs, so an internet connection is required.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish publishing. The site URL will appear in the Pages settings.

The game is published as a web game. Publishing it on Google Play as an Android app is a separate step.
